Derivação de um Código a partir da Gramática da Linguagem C
1. Linguagem escolhida
A linguagem escolhida para realizar esta atividade foi a linguagem C.

Escolhi C porque é uma linguagem bastante conhecida e possui uma estrutura
sintática que permite visualizar bem a relação entre uma gramática formal e um programa.
Para esta atividade, será utilizado um exemplo simples de atribuição com uma operação de soma.

2. Fonte da gramática consultada
Para realizar a atividade, foi consultada a documentação do cppreference,
na parte referente à linguagem C. A documentação apresenta informações sobre a sintaxe da linguagem,
incluindo expressões, operadores e instruções.

Fonte principal:

cppreference — C language:
https://en.cppreference.com/w/c/language

Também foi consultado o GNU C Language Manual, principalmente a parte que explica expressões e operadores de atribuição.

GNU C Language Manual:
https://www.gnu.org/software/c-intro-and-ref/manual.html

A gramática de C é normalmente apresentada usando uma notação semelhante à BNF (Backus-Naur Form).
Nesta atividade, eu não utilizarei a gramática completa da linguagem, pois ela é bastante extensa.
Serão selecionadas apenas algumas regras necessárias para representar o código escolhido.

3. Produções selecionadas
Para facilitar a demonstração, foram selecionadas e simplificadas algumas regras da gramática de C:

<expression-statement> ::= <expression> ";"

<expression> ::= <assignment-expression>

<assignment-expression> ::= <identifier> "=" <additive-expression>

<additive-expression> ::= <multiplicative-expression>
                        | <additive-expression> "+" <multiplicative-expression>

<multiplicative-expression> ::= <primary-expression>

<primary-expression> ::= <identifier>
                       | <constant>

<identifier> ::= "x"

<constant> ::= "5" | "3"

Essas regras são uma versão simplificada para fins didáticos. Elas não representam toda a gramática da linguagem C,
mas são suficientes para gerar o pequeno trecho de código escolhido.

A documentação do cppreference mostra que uma instrução de expressão em C é formada por uma expressão seguida de ponto e vírgula.
Ela também apresenta a atribuição e os operadores aritméticos como partes das expressões da linguagem.

4. Código que será gerado
O código escolhido para realizar a derivação é:

x = 5 + 3;

Esse é um exemplo pequeno, mas permite mostrar mais de uma regra da gramática. Nele, a variável x recebe o resultado da soma entre 5 e 3.

É importante observar que, em um programa C completo, a variável x precisaria estar declarada. Porém, para o objetivo desta atividade, estamos analisando somente a construção sintática da instrução de atribuição.

5. Derivação passo a passo
A derivação começa pelo símbolo inicial:

<expression-statement>

Primeiro, aplicamos a regra:

<expression-statement> ::= <expression> ";"

Então temos:

<expression-statement>
-> <expression> ";"

Agora aplicamos:

<expression> ::= <assignment-expression>

Resultado:

<expression-statement>
-> <expression> ";"
-> <assignment-expression> ";"

Em seguida, utilizamos a regra de atribuição:

<assignment-expression> ::= <identifier> "=" <additive-expression>

Assim:

<expression-statement>
-> <assignment-expression> ";"
-> <identifier> "=" <additive-expression> ";"

Para gerar a variável x, usamos:

<identifier> ::= "x"

Portanto:

<expression-statement>
-> <identifier> "=" <additive-expression> ";"
-> "x" "=" <additive-expression> ";"

Agora precisamos gerar a expressão 5 + 3.

Para isso, usamos a regra:

<additive-expression> ::= <additive-expression> "+" <multiplicative-expression>

Neste exemplo, podemos representar a expressão como:

<additive-expression>
-> <multiplicative-expression> "+" <multiplicative-expression>

Depois, cada <multiplicative-expression> pode ser substituído por <primary-expression>:

<additive-expression>
-> <primary-expression> "+" <primary-expression>

Agora utilizamos:

<primary-expression> ::= <constant>

obtendo:

<additive-expression>
-> <constant> "+" <constant>

Por fim, substituímos os dois <constant> pelos valores desejados:

<constant> ::= "5" | "3"

Assim:

<additive-expression>
-> "5" "+" "3"

Juntando todas as etapas, temos a derivação completa:

<expression-statement>
-> <expression> ";"
-> <assignment-expression> ";"
-> <identifier> "=" <additive-expression> ";"
-> "x" "=" <additive-expression> ";"
-> "x" "=" <primary-expression> "+" <primary-expression> ";"
-> "x" "=" <constant> "+" <constant> ";"
-> "x" "=" "5" "+" "3" ";"

Chegamos finalmente à sequência de símbolos:

x = 5 + 3;

6. Símbolos terminais e não terminais
Durante a derivação, podemos perceber que existem dois tipos principais de símbolos.

Os símbolos não terminais são aqueles que ainda podem ser substituídos por meio de alguma regra de produção. Neste exemplo, temos:

<expression-statement>
<expression>
<assignment-expression>
<additive-expression>
<multiplicative-expression>
<primary-expression>
<identifier>
<constant>

Já os símbolos terminais são aqueles que aparecem no resultado final e não precisam mais ser substituídos.

Neste caso, os principais terminais são:

x
=
5
+
3
;

Por exemplo, <identifier> é um não terminal, pois ainda precisa ser substituído. Quando aplicamos a regra <identifier> ::= "x", chegamos ao terminal x.

O mesmo acontece com <constant>, que pode ser substituído por 5 ou 3.

7. Resultado final
Depois de aplicar todas as regras selecionadas, o código gerado é:

x = 5 + 3;

A derivação mostra, passo a passo, como começamos com um símbolo não terminal e
fomos substituindo cada parte até chegar somente aos símbolos que aparecem no código.

Esse exemplo também ajuda a perceber que a gramática funciona como uma espécie de conjunto de regras para
determinar quais construções podem formar uma instrução válida na linguagem. No caso analisado, a regra de atribuição permitiu construir x = ..., enquanto as regras de expressão permitiram construir 5 + 3.

Portanto, mesmo utilizando apenas uma pequena parte da gramática de C, foi possível relacionar os conceitos estudados de símbolos terminais,
símbolos não terminais, produções e derivação com um código real da linguagem.
